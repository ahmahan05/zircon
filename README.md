# Atelier

Журнал работ зубного техника: наряды, врачи, аналитика и голосовой ввод.

Каждый техник работает в своём аккаунте. Цены хранятся в копейках, экспорт — Excel для цеха и JSON-резервная копия.

## Возможности

- Регистрация и вход по почте (отдельные экраны)
- Наряды: врач, пациент, вид работы, цвет Vita, количество, сумма
- **Диктовать** в форме наряда: «наряд 1524, врач Иванов, циркон стандарт, цвет А2, две штуки»
- Сводка, аналитика, карточки врачей
- Excel-журнал и резервная копия JSON

## Запуск

Нужны Node 22 и `npm install`.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run typecheck
```

## Стек

React 19, TanStack Start, Tailwind v4, Better Auth, PostgreSQL / PGLite.
